Why the overlay exists

The seventeen overlay files are not upstream copies. They are the working versions
from the author's tree, taken against the commits above. Sixteen are source and
build files and one is a game settings file. Every one of them carries a line
saying it was modified by Colosseum Recomp on 2026-10-18, which is what GPL-3.0
section 5(a) asks for.

Five came in with the first commit, 8b12429:

   Makefile                        +8 -1   GAMECUBE_CONTROLLERS=ON by default for
                                          this GameCube title, forwarded to CMake
   lib/ModernGekko/CMakeLists.txt  +5 -0   links winhttp and bcrypt on Windows
   tools/frontend_config.cpp       +7 -1   config header uses the product name
   tools/moderngekko_run.cpp       +9 -0   default game window title is branded
   tools/moderngekko_launcher.cpp +1218 -78  the launcher itself: branded UI, disc
                                          selection and extraction, component
                                          install from the archives beside the
                                          launcher, module build with progress,
                                          module publishing, launch

One more came in later, on top of the pinned ModernGekko commit rather than in a
commit of its own:

   tools/moderngekko_port.cpp      +79 -1   the port resolves the module build
                                          sources at run time beside its own
                                          executable instead of using only the
                                          directory compiled into it, which stays
                                          as the development fallback

The counts are against the pinned commits. They leave out the one line each file
gains from the modification notice.

After the overlay is applied, lib/ModernGekko and lib/ModernGekko/vendor/dolphin
are dirty submodules. That is expected. Do not commit inside them. The overlay in
this repo is the record.
