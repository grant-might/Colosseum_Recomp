   note     This is roughly 880 MB. A plain clone of ModernGekko does not
            fetch it. You need it to build, so run:
              git -C ModernGekko-Template/lib/ModernGekko submodule update \
                  --init --depth 1 vendor/dolphin
            or pass --with-dolphin to bootstrap.sh.

Why the overlay exists

The five overlay files are not upstream copies. They are the working versions
from the author's tree, taken against the commits above.

   Makefile                      +7   GAMECUBE_CONTROLLERS=ON by default for this
                                      GameCube title, forwarded to CMake
   lib/ModernGekko/CMakeLists.txt   +5  links winhttp and bcrypt for first-run
                                        component download on Windows
   tools/frontend_config.cpp        +7  config header uses the product name
   tools/moderngekko_run.cpp        +9  default game window title is branded
   tools/moderngekko_launcher.cpp +1186  the launcher itself: branded UI, disc
                                        selection and extraction, component
                                        acquisition, module build with progress,
                                        module publishing, launch

Line counts against edd460a:

   tools/moderngekko_launcher.cpp   1273 upstream, 2382 here, +1186 / -77
   tools/moderngekko_run.cpp         470 upstream,  479 here,   +9 / -0

After the overlay is applied, lib/ModernGekko is a dirty submodule. That is
expected. Do not commit inside it. The overlay in this repo is the record.
